Stage 3: System Architecture Proposals & Selection

Selection Decision: Architecture #1 (Hybrid SSG + Client-Side Edge Compute) Approved • Author: agent-3-architect.

1. The 3 Architectural Options Evaluated

Architecture Model Hosting & Compute Monthly Cost Decision & Feasibility
#1: Hybrid SSG + Client-Side Math Cloudflare Pages Anycast Edge + Pure Client JS $0.00 / month APPROVED — Infinite scale, instant builds, zero server attack surface.
#2: Serverless Edge SSR Cloudflare Workers / Vercel Edge SSR $0–$50+/mo REJECTED — Spike traffic during festivals breaches free tier request limits.
#3: Pure Pre-Rendered Jamstack Static HTML for all dates/cities/languages $0/mo REJECTED — Requires generating 3 Billion files; builds timeout after 6 hours.
