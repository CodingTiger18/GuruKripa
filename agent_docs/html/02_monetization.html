2. Strict Zero-CLS Ad Containers

Every ad slot enforces layout containment (contain: layout style;) and reserved aspect-ratio styling, preventing any unexpected layout jump:

.gk-ad-wrapper {
  background: rgba(128, 0, 32, 0.02);
  border: 1px dashed rgba(212, 175, 55, 0.4);
  border-radius: 8px;
  contain: layout style;
  min-height: 90px; /* or 280px */
}

3. AdSense Compliance Checklist

  • Authorized Sellers: Root public/ads.txt published.
  • Originality: Public-domain Sanskrit texts paired with original English word-by-word Sabdartha and philosophical purports.
  • Cookieless Consent: Google Consent Mode v2 banner pre-integrated in src/main.js.
  • Privacy Policy Transparency: Explicit Google DART cookie disclosures, Google Ad Settings opt-out link, and CCPA Do Not Sell compliance.

5. Dynamic Single-Page Application (SPA) SEO Engine

GuruKripa features an automated client-side SEO updater (updateSEO()) that dynamically modifies:

  • Page Title & Meta Descriptions: Dynamically tailored for each view (Panchang, 12 Jyotirlingas, Stotras, Japa Mala, Moral Stories).
  • Canonical & OpenGraph Meta: Injects canonical URLs and OpenGraph preview banner (public/assets/og-banner.svg).
  • Schema.org JSON-LD: Generates multi-graph schemas including WebApplication, WebSite, BreadcrumbList, and interactive FAQPage rich snippets.
