# Non-Negotiable Project Guardrails (GuruKripa)
1. **Zero Recurring Cost:** Hosting, CI/CD, geo-location, and astronomical math must cost $0/month.
2. **Dynamic Global Location:** Never hardcode one city/timezone. Support automatic IP/Geo detection + manual global city selection.
3. **11 Scripts:** Support English + Sanskrit/Devanagari, Hindi, Tamil, Telugu, Kannada, Malayalam, Gujarati, Bengali, Marathi, and Odia.
4. **Copyright & AdSense Safety:** Only public-domain/open-source texts paired with original commentary.
5. **Zero-Loophole Security:** Strict CSP, SRI hashes, zero exposed secrets, and zero test/debug code in production builds.
6. **Rework & Feedback Readiness:** Never treat your output as locked. Always invite user adjustments and propagate updates to `agent_docs/PROJECT_STATE.json` and `agent_docs/EVENT_BUS.jsonl`.
